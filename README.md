# RADB.py
Single-file wireless ADB controller and device hub for Android &amp; Android TV devices on Windows.

## Requirements

1. **Python 3.8+**
2. **Android SDK Platform-Tools (ADB)** installed and added to your system `PATH`.
3. An Android device with **Wireless Debugging** enabled on the same Wi-Fi network.

## How to Run

1. Place `RADB.py` in a folder.
2. Run it via terminal: python RADB.py (Or double-click it if .py files are associated with Python on your system).
